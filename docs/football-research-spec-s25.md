# S25 research_only 試驗規格：波膽聚中、和局唱唔出、場次 Δλ

狀態：**研究軌**。凍結指紋不變、公開頁照讀凍結帳、每日凍結流程一分不改。
本規格只定義「可以試乜、點驗、幾時停」，唔授權任何寫入生產。

## 0. 三句診斷（收窄範圍）

1. **1-1／中間格太多** ＝ 聯合分佈嘅對角質量同相關結構不足，或者 λ 被拉去聯賽平均。
2. **和局唱唔出** ＝ 對角總質量偏低；同「眾數係 1-1」可以同時成立，修眾數 ≠ 修和局。
3. **近況／球員** 改嘅係 λ，唔係格型；改完眾數多數只由 1-1 搬去 2-1，和局校準另計。

## 1. 凍結參數清單（試驗期間一律鎖死）

- λ_H、λ_A 生成式 ＝ 現行凍結慢實力 ＋ 已過閘主客分拆攻防。**唔准重估**。
- 波膽同 1X2 **同一張矩陣**，禁止分叉。
- 賠率權重 = 0（市場只做研究 overlay 殘差診斷，唔做標籤、唔做特徵）。
- 波膽單格命中率：只作展示，永不入損失函數、永不回寫調參。

## 2. 禁止列（已否決，唔再開）

對手調整殘差、ρ(λ) 衰減、逐聯賽 μ、時間衰減 ξ、κ→λ、Rue–Salvesen γ、
五刀疊加、逐場近況特徵入凍結、最近 5 場入波率加權、Skellam 另開 1X2 軌、
把市場 calculator 當預測器、把公開站 ρ preset 寫入指紋、用完場 xG 倒算賽前盤。

## 3. 閘門（統一口徑）

主閘三項，全部要對照**現行生產軌**（唔用研究基準 0.2136）：

| 閘 | 通過條件 |
| --- | --- |
| RPS | ≤ 生產基準 |
| 實際比分格 log-loss | ≤ 生產基準 |
| ECE（1X2 十桶） | ≤ 生產基準 |

副閘（只用嚟殺死通過主閘但破壞其他盤嘅方案）：
對角總質量對經驗頻率（五大聯賽和局 23–26%）、大細 2.5 校準、頭八格覆蓋。

驗收協議：逐季 walk-forward（測試季賽果唔入擬合）、五大聯賽同全樣本分開報、
一次一把（唔准兩把同時開）。任何一季或全樣本輸返一項即停、留舊軌。

## 4. 試驗序（聯合分佈層，λ 鎖死）

| # | 試驗 | 改邊層 | 成功樣 | 失敗樣（即停） |
| --- | --- | --- | --- | --- |
| 1 | DIBP 對角膨脹，p 為**聯賽級常數**，D 只蓋 0–2 球和 | 聯合 | 對角質量↑、ECE 唔退、RPS ≤ 基準 | 所有場和機率齊升 |
| 2 | 雙變量 Poisson 共享衝擊 λ₃（一粒全局或一聯賽一粒） | 聯合 | 和局 ECE 改善、OU 唔明顯退 | totals 漂 |
| 3 | 邊際換 CMP／負二項（先唔加相關） | 邊際 | 肥尾／多零改善、1-1 眾數自然跌 | 高分格過肥 |
| 4 | 1 完再 2（DIBP on BP） | 聯合 | 主副閘齊過 | 參數搶方差 |
| 5 | 動態攻防（攻／守兩條獨立隨機遊走，各自精度） | 實力 | 逐季閘齊過 | 退化成時間衰減變種 |

硬規則：p 同 λ₃ 唔准逐場、唔准跟近況走；試驗 1–4 唔准同 5 同時開。

## 5. 場次 Δλ 層（三層輸出，中間層而家係零）

```text
第一層  凍結 λ      慢實力 ＋ 已過閘主客分拆        （永遠存在）
第二層  場次 Δλ     log λ 加法 shifter，賽前可觀測   （研究，過閘先升）
第三層  展開矩陣    同一套結構出 1X2／波膽           （唔准人為改和）
```

准用 shifter（只接受賽前已知、場場唔同、同長期攻防正交）：

| shifter | 條件 | 未齊時 |
| --- | --- | --- |
| δ_名單 | **官方名單已公布**先寫；核心前鋒／門將缺陣調呢場 λ，唔改長期攻防 | δ = 0，頁面細字「名單未出，用基準 λ」 |
| δ_密度 | 休息日／賽程密度，獨立驗 | δ = 0 |
| Δλ_市場 | no-vig 收盤 1X2＋OU 倒推市場 λ，**只做殘差診斷** | 不適用 |

紅燈退回規則：任何 shifter 資料缺失、時間戳唔可信、或者名單未公布 → 該場 Δλ = 0、
輸出等同基準凍結矩陣，卡面標明；紅燈場可睇、唔入戰績。

## 6. 資料層前置（球員項未齊之前唔碰凍結）

需要：穩定上陣分鐘、射門／賽前 projected xG、門將撲救、**公布名單時間戳**。
未齊 → 球員能力加總（Whitaker 式球員 Poisson → 隊 λ）唔開工。
完場 xG 唔係預測輸入。

## 7. 產品文案（可即刻做，指紋唔變）

- 波膽卡寫明：頂格 10–20% 係「最不意外」嘅比分，唔叫「估中」。
- 1X2 三條機率齊列，最高嗰條標金；和局歷史頻率 23–26% 一併寫。
- 對帳三格等第一批綠燈完場先出實數，唔准用回測充場。
